RED & GOLD WEDDING WEBSITE

1. Open index.html in a browser.
2. Keep index.html, styles.css, script.js, and the assets folder together.
3. Edit names, dates, event details, and venue directly in index.html.
4. Replace the story photo placeholder by adding your image to assets and changing .photo-placeholder in styles.css.
5. The RSVP is currently a front-end demo only. Connect it to Formspree, Google Apps Script, Firebase, Supabase, or your backend to save responses.
6. Deploy free using GitHub Pages, Netlify, or Vercel.
